코스 전경 특징

천연 지형을 그대로 살린 자연 친화적이고 도전적인 코스 설계는 물론, 석양과 함께하는 쾌적한 야간 라운딩의 명소로 손꼽히며 페어웨이와 그린 컨디션이 안정적으로 유지됩니다.

서코스 (West Course / 회원제)

회원제 18홀 중 하나인 서코스는 수려한 자연 경관과 조화롭게 설계되어 회원님들에게 최상의 플레이 환경을 제공합니다.

중코스 (Middle Course / 회원제)

전략적인 샷이 요구되는 중코스는 상급자에게도 만족감을 제공하며 정교한 두뇌 플레이의 묘미를 선사하는 회원제 코스입니다.

동코스 (East Course / 대중제 9홀)

탁 트인 시야를 자랑하는 대중제 9홀 코스입니다.

MEMBERSHIP GUIDE

블루원용인CC 개인 및 법인 회원권 상세 혜택 안내입니다.

정회원권 (개인)

정회원 1인 + 배우자(자녀) 1인 + 지정 1인

그린피 및 이용 혜택

  • • 정회원 / 배우자: 주중 75,000원 / 주말 95,000원
  • • 지정인: 주중 135,000원 / 주말 비회원가
  • ※ 지정인 타인 등재 가능
  • ※ 지정회원, 준회원은 주중에만 단독 부킹 가능

정회원권 법인 (반구좌)

정회원 1인 + 지정 2인

그린피 및 이용 혜택

  • • 정회원 / 배우자: 주중 75,000원 / 주말 95,000원
  • • 지정인(준회원): 주중 135,000원 / 주말 비회원가 (준회원 주중 7.5만/주말 9.5만 적용)
  • ※ 지정회원: 정회원의 배우자 1인, 임직원 1인 등재 가능
  • ※ 준회원/지정인 주중 부킹권 부여

정회원권 법인 (온구좌)

정회원 2인 + 준회원 1인 + 지정 5인

그린피 혜택

  • • 정/준회원/배우자: 주중 75,000원 / 주말 95,000원
  • • 지정인: 주중 135,000원 / 주말 비회원가

지정회원 등록 규정

  • • 지정 2인은 법인 임직원 등재 가능
  • • 지정 3인은 정회원/준회원의 배우자만 등재 가능
  • * 특이점: 배우자 미등록 시 지정 임직원으로 대체 추가 불가

개인 및 법인 공통 특별 혜택

• 멤버스 데이: 정회원 본인 생일이 속한 달의 주중 연 1회, 본인은 세금만 납부하고 이용

• 위임 혜택: 정회원이 홈페이지 예약 후 비회원 라운딩 가능 (위임 처리)

• 블루원상주CC 연계: 정/준회원 주중 30% 할인(91,000원), 주말 추천가(토/공휴일 18만, 일 17만)

• 콘도미니엄 혜택: 추천 요금 적용 가능

  • • 지정회원: 예약일 2주 전 09시 (실시간 선착순)
