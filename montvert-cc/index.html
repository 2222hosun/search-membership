36홀 다이내믹 코스 전경

명성산의 웅장함 속에서 36홀 대규모 코스를 여유롭게 즐기실 수 있습니다. 코스와 잔디 상태는 1년 내내 수준급으로 철저하게 관리됩니다.

클럽하우스

독수리가 날개를 활짝 편 듯한 웅장하고 독특한 외관 디자인

로비 & 안내데스크

레스토랑

라커룸

불필요한 요소를 덜어낸 세심하고 프라이빗한 공간

사우나

라운딩 후의 피로를 기분 좋게 풀어주는 힐링 시설

OUT 코스 (북코스) : 도전과 스릴

기암괴석과 계곡을 넘기는 샷 밸류가 높아 승부욕을 강하게 자극하는 남성적인 코스입니다.

IN 코스 (남코스) : 섬세함과 우아함

망무봉을 감싸는 완만한 지형과 계곡이 어우러져 잘 가꿔진 정원에서 플레이하는 듯한 정교함이 요구됩니다.

대유몽베르CC 정회원권

입회기간 5년 (이후 반환 또는 연장 가능) / 36홀 동일 조건 이용

분양가: 4억 원
  • 회원 구성 : 정회원 1인 + 지정회원 1인 + 동반 3인
  • 예약 횟수 : 주중 6회 / 주말 3회
  • 이용 그린피 안내
  • • 정회원 : 주중 88,000원 / 주말 98,000원
  • • 지정회원 : 주중 100,000원 / 주말 120,000원
  • • 동반자 : 주중 120,000원 / 주말 140,000원
  • • 위임가 : 주중 130,000원 / 주말 150,000원

주요 강력 혜택

  • 1. 무기명 위임 가능: 비회원 4인 주중/주말 위임 가능 (예약 횟수 내 주중 3회, 주말 1회 위임가 적용)
  • 2. 동반자 혜택: 정회원 동반 시, 동반자 3인 전원 주중/주말 '동반자 그린피' 혜택 적용
  • 3. 지정회원 권한: 주중 단독 라운딩 가능 (동반자 3인도 동반자 그린피 적용) / 단, 주말은 단독 라운딩 불가하며 정회원 동반시에만 지정회원가 적용
  • 4. 높은 활용도: 지정회원은 타인으로 등록 가능
