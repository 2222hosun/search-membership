MEMBERSHIP GUIDE

남서울CC 정회원권 혜택 안내입니다. (준회원·가족회원 제도 없음)

개인 / 법인 정회원권 정회원 1인 기준

가족회원 없이 정회원 위주의 예약 환경을 유지합니다.

  • • 정회원 그린피 혜택: 주중 100,000원 / 주말 140,000원
  • • 월별 기본 예약: 주중 2회 / 주말 1회
  • ※ 법인 회원권 구성 유의사항:
    법인은 반구좌 입회가 절대 불가하며, 반드시 개인 회원권 2구좌를 매입하여 법인 온구좌(정회원 2인)로 구성해야 합니다.
    이때 매수하는 2구좌의 성별(남/여)에 맞게 법인 등재가 이루어집니다.
