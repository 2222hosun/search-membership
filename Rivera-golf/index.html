경기도 광주시 / 18홀

신안CC

경기도 안성시 / 27홀

웰리힐리CC

강원도 횡성군 / 36홀

에버리스CC

제주도 제주시 / 27홀

제주의 아름다운 바다와 한라산 조망을 동시에 만끽하며 이국적인 분위기 속에서 품격 있는 라운드를 선사합니다.

MEMBERSHIP GUIDE

정회원권, 레드회원권 및 M-VIP 회원권 혜택 구조입니다.

정회원권

정회원 1인 구성

  • • 그린피: 주중 110,000원 / 주말 125,000원
  • • 특전: 신안그룹 골프장 할인 혜택
  • • 입회 조건: 개인, 법인 구분 없이 매매 가능 (법인 반구좌 가능)

레드회원권 3구좌 묶음

정회원 1인 + 지정 1인 구성

  • • 예약 횟수: 주중 2~4회 / 주말 2~3회 (리베라, 신안, 그린힐 통합 / 에버리스·웰리힐리 횟수 제한 없음)
  • • 그린피 (리베라·신안·그린힐·에버리스·웰리힐리 동일): 주중 110,000원 / 주말 125,000원
  • • 참고사항: 3구좌 묶음 형태로 취득세 및 개서료 구좌당 발생

레드 M-VIP 회원권 10억원 반환형

레드정회원 1 + 등록 1 + 무기명 3

  • • 예약 횟수: 주말 3회 / 주중 6회
  • • 그린피: 레드정회원 주중 11만 / 주말 12.5만 | 등록·무기명 주중 8만 / 주말 9만 (웰리힐리·에버리스 주중 12만 / 주말 14만)
  • • 혜택: 웰리힐리파크 및 에버리스 골프텔 회원대우, 5년/10년 반환 (반환 시 리베라CC 레드회원권 유지)

레드 M-VIP 회원권 20억원 반환형

레드정회원 1 + 무기명 4

  • • 예약 횟수: 주말 5회 / 주중 9회
  • • 그린피: 무기명 주중 8만 / 주말 9만 (웰리힐리·에버리스 주중 12만 / 주말 14만)
  • • 혜택: VIP 락카 제공, 웰리힐리파크 및 에버리스 골프텔 회원대우 이용
